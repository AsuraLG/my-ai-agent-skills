# 攻略正文参考规范

AI 在 WRITE_GUIDE 阶段撰写 `markdown/guide.md` 时的结构参考。`guide.md` 的初始骨架由 `init-guide.js` 根据天数和来源类型自动生成，AI 在此基础上填充实际内容。

---

## 动态参数来源

以下信息来自 `guide.config.json`，AI 应据此调整措辞和结构：

| 参数 | 字段 | 影响 |
|------|------|------|
| 行程天数 | `days` | 决定 Day 1 ~ Day N 的章节数量 |
| 素材来源类型 | `sourceType` | `xhs` = 小红书 / `manual` = 手动整理 / `other` = 其他平台 |
| 目的地 | `destinationName` | 用于标题和正文中的地名 |

---

## 正文结构

### 头部引言（必填）

一句话说明适合人群和数据来源。init-guide.js 已生成骨架。

### 数据来源说明（必填）

- 采集时间（必填）
- 入选素材数量（必填）
- 关键词和筛选标准（仅 sourceType=xhs 时填写，其他来源省略）

### 每日行程 Day 1 ~ Day N（必填）

天数由 `guide.config.json` 的 `days` 字段决定。每天的结构：

```
# Day N｜行程标题

## 上午：景点 / 活动（必填）
- 推荐地点
- 参考时长
- 注意事项

## 中午：餐饮建议（选填 — 有相关素材时填写）

## 下午：景点 / 活动（必填）
```

**条件内容：** 如果素材中包含用户评论数据（`top_comments` 非空），可在相关段落后用引用块摘录：
```markdown
> 「评论内容摘录」
```
没有评论数据时不要生造此部分。

### 实用信息（必填）

- 交通（必填）：到达方式、市内交通
- 住宿推荐（选填）：有相关素材时填写
- 费用参考（选填）：有相关素材时填写

### 使用说明（必填）

提醒读者以现场信息为准。init-guide.js 已根据来源类型生成合适的免责声明。

## Markdown 语法约束

- `#` / `##` / `###` 标题（最多三级）
- `- ` 无序列表
- `1.` 有序列表
- `> ` 引用块（用于评论摘录）
- `---` 分隔线
