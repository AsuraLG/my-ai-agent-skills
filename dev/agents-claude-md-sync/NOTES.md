# agents-claude-md-sync 开发记录

## 设计决策

- 以 `AGENTS.md` 为唯一权威源，`CLAUDE.md` 只保留严格的 `@AGENTS.md` 引用。
- 文件比较使用字节级 `cmp`；备份使用最大已有编号加一，避免覆盖或回填。
- 将易出错的比较、备份和写入逻辑集中到无第三方依赖的 POSIX shell 脚本，skill 只负责编排和报告。
