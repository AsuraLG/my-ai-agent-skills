# 模板 A：叙事卡片组（童趣档）

给非技术受众（小孩/家人/朋友/低学历档）解释主题、概念、文档、代码或报错。「讲给别人听」的场景，讲故事最有效。

## 结构规格

1. 大标题 + 一行副标题（"看图 3 分钟就懂"式）
2. **3~5 幕，硬封顶**（儿童的核心是消化率，多即伤害）：每幕一张卡片——卡片标题 + 一幅主视觉 + 1~2 句点睛文字
3. 一张渐变总结卡：一句话说清本质 + 小字补充（术语原名、代表产品等）

## 叙事顺序

先讲"是什么" → 类比连接已知 → 按需补充细节 → 落在"对你意味着什么"。

## 视觉要求

- 每幕一幅主视觉：内嵌 SVG 手绘（房子、小人、表情等拟人化简笔、气泡、连线）
- 暖色奶油底（如 `#FFF8F0`）、大号圆角卡片、鲜艳柔和配色
- 大字号：标题 ≥ 48px，正文 ≥ 22px；Emoji 可作图标点缀
