# 模板 C：剖析卡片组（技术档）

给技术受众（工程师/大学生及以上）解释主题、概念或技术文档。他们要全量信息：机制、权衡、边界。

## 结构规格（5~8 张卡，复杂主题可到 10 张）

1. **概览卡**：定义 + 架构图（SVG 示意）
2. **机制详解卡 2~4 张**：允许多段落文字、卡内代码块、流程图/时序图
3. **权衡与边界卡**：对比表
4. **总结卡**：核心设计哲学 + 适用边界

## 内容要求

- 深度优先在**卡片内部**展开（多段落、表格、代码块），而不是只靠加卡片
- 用正式术语——不用反而显得轻视；聚焦有趣的部分：权衡、边界情况、设计决策
- 简洁，尊重受众既有知识

## 视觉要求

- 中性底色（浅色或深色均可），允许高信息密度
- 架构图/流程图/时序图风格，等宽字体标注代码与技术名词
