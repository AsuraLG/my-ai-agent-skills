# 模板 B：结论先行卡片组（商务档）

给商务受众（经理/总监/产品经理/40+ 岁）解释主题、概念、文档、代码或报错。他们关心影响、时间线、风险、成本，不关心机制细节。

## 结构规格（3~5 张卡）

1. **结论卡**：一句话答案 + 关键数字
2. **影响卡**：对受众业务的影响、时间线、成本
3. **方案或风险卡**：允许对比表、时间线、风险矩阵图形
4. **决策建议卡**：用决策框架收尾（"这意味着我们应该……"）

## 内容要求

- 能量化就量化
- 跳过实现细节，除非被问到
- 聚焦"需要做什么决定"

## 视觉要求

- 干净专业配色：白底 + 单一品牌色 + 灰色系
- 字号适中，信息呈现以表格、时间线为主，图形为辅
- 不用卡通元素、不用 emoji 表情
